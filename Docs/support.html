Backu for iPhone, iPad and Mac

Getting started

  1. Open Servers and choose a provider, or Custom S3.
  2. Follow the numbered steps to create a bucket and an access key. The Open button takes you to the right page.
  3. Enter the bucket, endpoint and key, then tap Test Connection. Backu lists the folder, writes a probe object and reads it back.
  4. In Settings → Backup, enable automatic backup and choose the server, folder and whether mobile data is allowed.

The rest of the library — grid, viewer, tags, people, search — works without a server.

Where do my photos go?

Into the folder you chose in your bucket:

  • Photos/2025/06/IMG_4821-ab12cd34.jpg — the original file, unchanged.
  • Photos/2025/06/IMG_4821-ab12cd34.jpg.json — tags, people, face boxes, camera, location and SHA-256.
  • .backu/thumbs/… and .backu/index.json — previews and a search index for other devices.

Nothing is stored on a Backu server. The app uploads directly to your bucket.

Common questions

Which providers work?

Anything with an S3-compatible API: Amazon S3, Backblaze B2, Cloudflare R2, MinIO, Wasabi, Synology and custom gateways. Use path-style addressing if your service requires it (most appliances do).

I got “Access denied”.

The key needs ListBucket, GetObject and PutObject on that bucket. Check the bucket name and region too; a key for another region will fail.

Can I use more than one server?

Yes. Add as many as you like and pick the automatic-backup destination in Settings. Photos can exist on several servers.

What happens to the people I name?

Names and face boxes are written into each photo's sidecar and the shared index, so other devices opening the same bucket see them. Face feature vectors stay on the device that analysed them.

How do I restore or open the bucket elsewhere?

Add the same server on another iPhone, iPad or Mac. Backu reads .backu/index.json, shows previews, and downloads originals when you open them.

Is there a subscription?

No. Backu is free and open source under the MIT licence. If it is useful, you can sponsor development from Settings → Support Backu or on GitHub Sponsors.

Report a bug

Open an issue at github.com/oscartbeaumont/backu/issues. Include the iOS/macOS version, provider and the exact error message if there is one. Never paste your secret key.
